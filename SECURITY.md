# Security Policy

## Supported Versions

Only the latest `1.x` release line actively receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately via [GitHub Security Advisories](https://github.com/scoobingoo/telegram-miniapp-bot-starter/security/advisories/new).

Include as much of the following information as possible:
- Type of issue (e.g., authentication bypass, webhook signature verification, injection, SSRF)
- Affected component (`apps/server`, `apps/admin`, `apps/miniapp`, `packages/nestjs-grammy`, `packages/shared`)
- Step-by-step instructions or a minimal reproduction test case

We aim to acknowledge reports within 48 hours and publish a fix and advisory once verified.
